# E 组交付目录

本目录用于交付自动集成实现、兼容性报告、fallback 报告和最终验收结果。

建议正式交付文件：

1. `handoff.manifest.json`
2. `integration-readme.md`
3. `assembly-plan.md`
4. `compatibility-report.md`
5. `fallback-report.md`
6. `acceptance-checklist.md`
7. `assembly/` 目录
8. `artifacts/` 目录

当前仅提供模板：

1. `handoff.manifest.template.json`
