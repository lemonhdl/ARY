# C 组交付目录

本目录用于交付前端产品壳、页面依赖清单和 adapter 契约。

建议正式交付文件：

1. `handoff.manifest.json`
2. `route-map.json`
3. `page-dependencies.json`
4. `adapter-contract.md`
5. `fallback-rules.md`
6. `shell-readme.md`
7. `app-shell/` 目录

当前仅提供模板：

1. `handoff.manifest.template.json`

正式交付时请将模板复制为 `handoff.manifest.json`。
