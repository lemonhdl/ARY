# 4 数据边界流程

flowchart LR
 U[参赛者提交] --> A[ARY 平台]
 A --> C{数据是否可用}
 C -->|不可用| M[页面显示数据缺失]
 C -->|可用| E[返回本次评测结果]
 E --> V[页面显示评测完成]
 C -->|再次不可用| M2[再次显示数据缺失]
 M2 --> B[平台未保留受限数据继续使用]

| 证据 | 含义 |
| --- | --- |
| 未提交无结果 | **结果不是页面预置。** |
| 不可用时缺失 | **平台不能凭空完成评测。** |
| 可用时有结果 | **平台可以使用本次可用结果。** |
| 再次不可用后缺失 | **平台没有把受限数据保存成长期可用数据。** |
