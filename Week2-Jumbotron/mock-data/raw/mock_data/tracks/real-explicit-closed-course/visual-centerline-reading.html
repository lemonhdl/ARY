主视觉几何轨道曲线

输出

  • 曲线点位：visual-centerline.track.json
  • runtime profile：visual-centerline.runtime.track.profile.json
  • 扫描记录：visual-centerline.scan-records.json
  • 验证：visual-centerline.validation.json

方法

  • 用原始底图作为视觉来源，不用页面截图。
  • 用既有 profile 只作为粗种子，沿法线扫描冰蓝/银白赛道带。
  • 对检测点做闭合平滑，并根据 y 位置生成 far / mid / near 的视觉 depth。
