ARY / Single-Machine Monorepo

ARY 最小可运行骨架

单进程 Node.js Web 应用，统一托管 Public、Admin、Live、Screen 页面，并从 runtime-data 读取运行态数据。

Public

公开端入口和主路径占位。

Admin

管理端入口和 dashboard 占位。

Live Hall

Live Hall 和 Projection 占位。

Screen

大屏展示入口和占位。

Race Page

单场赛事公开页，支持按 raceId 直接进入。

Works

公开作品墙与作品详情入口。

Results

公开赛果入口，读取已发布 Award / Report。

Review

公开复盘入口，读取已发布 Review。

Rider Profile

公开 Rider 档案与证据摘要入口。

Cooperation

报名、办赛与赞助合作入口。

A-Rider Replay

查看 A-Rider 样例事件、握手契约、快照与验签集成状态。
